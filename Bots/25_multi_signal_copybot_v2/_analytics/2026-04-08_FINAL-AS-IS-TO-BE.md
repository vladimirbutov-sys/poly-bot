## #4. Hedge Detection — новая логика

### AS IS
**Нет.** Бот копирует каждое действие игрока без учёта его существующих позиций.

### TO BE
```python
HEDGE_DETECTION_ENABLED = True
HEDGE_THRESHOLD_USD = 10000

def is_hedge(player_wallet, condition_id, action_outcome):
    """Если игрок держит >$10K на противоположной стороне — это хедж, не сигнал"""
    opposite = 'No' if action_outcome == 'Yes' else 'Yes'
    pos = api.get_position(player_wallet, condition_id, opposite)
    return pos and pos.get('currentValue', 0) >= HEDGE_THRESHOLD_USD
```

**Уверенность: HIGH (для конкретного кейса)**

**Обоснование (один точный случай):**
- 07.04 21:48 Car купил No @ 0.68 на $144 на "US x Iran ceasefire by April 7"
- Одновременно Car держал **234,223 shares Yes ($233K)** на этом же рынке
- Это был **очевидный хедж**, не реальное мнение Car
- Наш бот скопировал No → потерял $5.54
- При резолве Yes (что и случилось) удержание No привело бы к -$144

**Риск:**
- Иногда "хедж" — это разворот стратегии (игрок передумал)
- Дополнительный API запрос на каждое решение (+0.3 сек latency)
- Только 1 case в нашей истории — слабая выборка

## #5. Не следовать тактическим выходам (holding < 1 час)

### AS IS
**Бот следует за любой продажей signal_player, даже если позиция была короткой.**

### TO BE
```python
SKIP_FOLLOW_IF_HOLDING_HOURS_LT = 1.0

def should_follow_sell(player_wallet, condition_id):
    holding_time = api.get_position_age(player_wallet, condition_id)
    if holding_time.total_seconds() < SKIP_FOLLOW_IF_HOLDING_HOURS_LT * 3600:
        return False  # tactical exit, not signal
    return True
```

**Уверенность: MEDIUM**

**Обоснование:**
- Конкретный кейс: Car купил Iran ceasefire April 30 @ 0.27, **продал через ~23 часа** @ 0.28 (+9%)
- Реальная цена потом ушла к 0.85+ когда стало ясно про перемирие
- **Если бы держали до резолва — было бы +$185 вместо +$7**
- Однако holding 23 часа > 1 час, не сработал бы фильтр

**Лучше формула:** не "holding < 1h", а **по объёму продажи**:
- Если игрок продал < 30% позиции → это балансировка, не выход. Игнорировать.
- Если продал >= 50% позиции → это реальный exit, копировать.

**Уверенность пересмотрена: MEDIUM** (нужно ещё думать над формулой)


- **Простое изменение, без рисков**

**Риск:** если API закроет нас по rate limit — может быть нужен fallback на 10 сек.

## #8. ORDER_TTL_SECONDS — снизить с 1800 до 600

### AS IS
```python
ORDER_TTL_SECONDS = 1800  # 30 min
```

### TO BE
```python
ORDER_TTL_SECONDS = 600  # 10 min
```

**Уверенность: HIGH**

**Обоснование:**
- На горячих рынках цена двигается за 1-5 минут
- Лимит ордер на старой цене 30 мин — это устаревший snapshot
- Если за 10 мин не исполнился — лучше отменить и пересчитать
- Парная мера к slippage: больше slippage чтобы попасть, меньше TTL чтобы не застрять

**Риск:** на низколиквидных рынках 10 мин может быть мало — пропустим прибыльные ставки.
