# Математическая модель копи-трейдинг бота: копирование Denizz на Polymarket

**Дата:** 2026-04-10

---

## Краткая выжимка

Модель определяет размер ставки и решение по входу/выходу на основе 6 параметров. Базовый масштаб -- 1:500 (наш банкролл $2,000 vs Denizz ~$1,000,000). Формула использует множители, калиброванные на реальных бэктест-данных Denizz. Ключевой вывод: не все сделки Denizz стоит копировать -- модель отклоняет ~40% его трейдов из-за проскальзывания, низкого ratio или перекоса портфеля.

---

## 1. Базовые константы

| Параметр | Значение |
|----------|----------|
| Банкролл Denizz (B_d) | $1,000,000 |
| Наш банкролл (B_us) | $2,000 |
| Масштаб (scale) | 1:500, то есть k = 0.002 |
| Максимальная ставка (max_bet) | $200 (10% банкролла) |
| Минимальная ставка (min_bet) | $2 |
| Максимум на одну позицию (max_position) | $200 (10% банкролла) |
| Максимум на один рынок (обе стороны) | $300 (15% банкролла) |

**Почему 10% лимит на позицию:**
Наш банкролл маленький ($2,000). Одна неудача на $400 -- это -20%, что разрушительно. При лимите в 10% даже 3 подряд убытка = -30%, что терпимо при WR 88%.

---

## 2. Формула размера ставки (ENTRY)

### 2.1 Основная формула

```
our_bet = base_bet * M_ratio * M_tier * M_slip * M_conc * M_entry
```

Где:

**base_bet** = Denizz_bet_usd * k = Denizz_bet_usd * 0.002

Это стартовая точка -- линейное масштабирование ставки Denizz. Затем мы корректируем её пятью множителями.

---

### 2.2 Множитель 1: M_ratio (ratio = новая ставка / текущий портфель по позиции)

Этот множитель отражает **уверенность Denizz** -- чем больше он добавляет относительно уже вложенного, тем сильнее сигнал.

| Ratio Denizz | M_ratio | Обоснование |
|-------------|---------|-------------|
| < 5% | 0.3 | Рутинное ребалансирование. WR 50%, ROI -0.4%. Почти всегда пропускаем |
| 5-15% | 0.7 | Умеренное добавление. WR 100%, но только 2 позиции -- мало данных |
| 15-30% | 1.5 | **Лучший бакет.** WR 92%, ROI +17.5%, 12 позиций. Максимальный множитель |
| 30-50% | 1.0 | Хороший сигнал. WR 67%, ROI +5.6%. Нейтральный множитель |
| 50-80% | 0.8 | Крупное добавление. WR 92%, но ROI только +3.8% -- позиция уже зрелая |
| 80-100% | 0.5 | Почти удвоение позиции. WR 100%, но ROI +1.0% -- очень поздний вход |
| > 100% | 0.0 | **Блокировка входа.** Единственный кейс: WR 0%, ROI -11.0%. Новая позиция с нуля -- непредсказуемо |

**Как считать ratio:**

```
ratio = new_buy_usd / current_position_usd
```

Если current_position_usd = 0 (новая позиция), то ratio = бесконечность (> 100%), и M_ratio = 0.0 -- модель НЕ входит.

**Исключение для новых позиций:** Если Denizz открывает новую позицию И его портфель по ней сразу попадает в бакет $20K+ (то есть первоначальная покупка >= $20,000), мы переопределяем M_ratio = 0.6. Это основано на том, что позиции $20K+ имеют WR 100% и ROI +14.4%.

---

### 2.3 Множитель 2: M_tier (ценовой тир)

Определяется по **текущей рыночной цене** (best ask), а не по цене входа Denizz.

| Ценовой тир (ask price) | M_tier | Обоснование |
|--------------------------|--------|-------------|
| 2-15c | 0.4 | Высокий риск, тонкая ликвидность. Потенциал огромный (x5-x10), но Denizz редко торгует здесь |
| 15-50c | 1.3 | **Лучшая зона по бэктесту.** WR 88%, ROI +11.2%. Максимальный множитель |
| 50-82c | 1.0 | Нормальная зона. Хорошая ликвидность, умеренный потенциал |
| 82-95c | 0.7 | Низкий апсайд (5-18c). Нужна высокая уверенность. Снижаем размер |
| 95-99c | 0.3 | Минимальный апсайд (1-5c). Только при идеальных остальных параметрах |

**Пример:** Рынок торгуется на 35c -- это тир 15-50c, M_tier = 1.3. Потенциальная прибыль при выигрыше: (100 - 35) / 35 = 186%.

---

### 2.4 Множитель 3: M_slip (проскальзывание)

Проскальзывание = разница между ценой входа Denizz и ценой, по которой мы реально можем купить.

```
slippage = our_actual_price - denizz_avg_entry
```

Допустимое проскальзывание зависит от ценового тира -- при дешевых ценах мы можем позволить больше, при дорогих каждый цент критичен.

| Ценовой тир | Макс. допустимое проскальзывание | Формула M_slip |
|-------------|----------------------------------|----------------|
| 2-15c | 5c | M_slip = max(0, 1 - slippage / 0.05) |
| 15-50c | 3c | M_slip = max(0, 1 - slippage / 0.03) |
| 50-82c | 2c | M_slip = max(0, 1 - slippage / 0.02) |
| 82-95c | 1c | M_slip = max(0, 1 - slippage / 0.01) |
| 95-99c | 0.5c | M_slip = max(0, 1 - slippage / 0.005) |

**Как это работает:**
- Если проскальзывание = 0: M_slip = 1.0 (без потерь)
- Если проскальзывание = половина допустимого: M_slip = 0.5 (режем ставку вдвое)
- Если проскальзывание >= допустимого: M_slip = 0.0 (блокировка входа)

**Пример:** Denizz купил по 40c, наш ask = 42c. Тир 15-50c, допуск 3c. Slippage = 2c. M_slip = 1 - 2/3 = 0.33. Ставка уменьшается втрое.

---

### 2.5 Множитель 4: M_conc (концентрация -- наша существующая позиция)

Защита от перекоса портфеля. Если мы уже много вложили в этот рынок, добавляем меньше или не добавляем вовсе.

```
concentration = our_existing_position_usd / B_us
```

| Концентрация | M_conc | Обоснование |
|--------------|--------|-------------|
| 0% (новая позиция) | 1.0 | Чистый вход |
| 0-3% ($0-60) | 1.0 | Небольшая позиция, можно добавлять свободно |
| 3-5% ($60-100) | 0.8 | Позиция ощутима, слегка снижаем |
| 5-8% ($100-160) | 0.5 | Позиция заметная, добавляем осторожно |
| 8-10% ($160-200) | 0.2 | Близко к лимиту, минимальное добавление |
| >= 10% ($200+) | 0.0 | **Блокировка.** Лимит на позицию достигнут |

**Непрерывная формула (для программирования):**

```
M_conc = max(0, 1 - (concentration / 0.10)^1.5)
```

Это дает плавное снижение: при 5% concentration M_conc = 0.65, при 8% M_conc = 0.28.

---

### 2.6 Множитель 5: M_entry (наша цена входа vs Denizz)

Отражает, входим ли мы дешевле или дороже Denizz. Если дешевле -- у нас лучше условия, увеличиваем. Если дороже -- условия хуже, уменьшаем.

```
price_advantage = denizz_avg_entry - our_actual_price
```

| Наша цена vs Denizz | M_entry | Смысл |
|---------------------|---------|-------|
| Мы дешевле на 3c+ | 1.2 | Мы получили лучшую цену -- бонус |
| Мы дешевле на 1-3c | 1.1 | Небольшое преимущество |
| Одинаковая (+-1c) | 1.0 | Нейтрально |
| Мы дороже на 1-3c | 0.9 | Небольшой штраф |
| Мы дороже на 3c+ | Учтено в M_slip | M_slip уже наказывает |

**Обратите внимание:** M_entry и M_slip частично пересекаются для случая "мы дороже". Но M_entry бонусирует случай "мы дешевле", чего M_slip не делает. При slippage > 0 работает M_slip (штраф). При slippage < 0 (мы дешевле) M_slip = 1.0, а M_entry дает бонус.

**Упрощенная формула:**

```
Если our_price <= denizz_avg_entry:
    M_entry = min(1.2, 1.0 + (denizz_avg_entry - our_price) / 0.05)
Иначе:
    M_entry = 1.0  (штраф уже через M_slip)
```

---

### 2.7 Финальные ограничения

После расчета our_bet применяем ограничения:

```
our_bet = max(min_bet, min(our_bet, max_bet))
```

Но также:

```
our_bet = min(our_bet, max_position - our_existing_position_usd)
```

То есть итоговая ставка не может привести к превышению лимита в $200 на позицию.

**И блокировка, если итоговый bet < $2:**
Если модель дает ставку меньше $2 -- не входим. Комиссии и проскальзывание на $1-2 ставках убивают прибыльность.

---

### 2.8 Множитель по размеру портфеля Denizz (бонусный фильтр)

Данные бэктеста показывают, что размер позиции Denizz сам по себе -- сильный сигнал:

| Портфель Denizz по позиции | WR | ROI | Рекомендация |
|----------------------------|-----|------|-------------|
| $100-500 | 60% | +1.4% | Слабый сигнал. Применяем доп. фильтр: M_portsize = 0.5 |
| $500-2K | 100% | +6.9% | Хороший. M_portsize = 1.0 |
| $2K-5K | 100% | +2.4% | Хороший. M_portsize = 1.0 |
| $5K-20K | 55% | +0.9% | Слабый! M_portsize = 0.4 |
| $20K-50K | 100% | +14.4% | Отличный. M_portsize = 1.3 |
| $50K-100K | 100% | +8.0% | Отличный. M_portsize = 1.2 |
| $100K+ | 100% | +23.4% | Лучший. M_portsize = 1.5 |

**Обновленная формула с этим фильтром:**

```
our_bet = base_bet * M_ratio * M_tier * M_slip * M_conc * M_entry * M_portsize
```

**Важный нюанс по $5K-20K бакету:** WR всего 55% при ROI +0.9%. Это аномалия -- возможно, здесь Denizz экспериментирует или хеджирует. Модель ставит M_portsize = 0.4, то есть урезает ставку на 60%.

## 3. Правила ВЫХОДА (EXIT)

### 3.1 Основная логика

Выход происходит, когда Denizz продает. Решение: продавать полностью, частично, или держать.

```
exit_action = f(denizz_sell_ratio, our_profit_status, current_bid, our_entry)
```

### 3.2 Denizz sell_ratio

```
denizz_sell_ratio = shares_sold / total_shares_held
```

| Sell ratio Denizz | Интерпретация | Наше действие |
|-------------------|---------------|---------------|
| < 10% | Взятие мелкой прибыли / ребалансирование | **Не выходим.** Держим |
| 10-30% | Частичная фиксация прибыли | Продаем 25% нашей позиции |
| 30-60% | Значительная фиксация | Продаем 50% нашей позиции |
| 60-90% | Серьезный выход | Продаем 75% нашей позиции |
| > 90% | Полный выход | **Продаем 100%** |

### 3.3 Наш порог безубытка

Прежде чем выходить, проверяем: выходим ли мы с прибылью или убытком.

```
our_pnl = current_bid - our_avg_entry
```

| Ситуация | Поведение |
|----------|-----------|
| our_pnl > 0 (в прибыли) | Следуем таблице sell_ratio выше |
| our_pnl = 0 (в безубытке) | Следуем, но sell_ratio < 30% -- не выходим (ждем прибыль) |
| our_pnl < 0 (в убытке) | Только при sell_ratio > 60% -- фиксируем убыток. Иначе держим |

**Обоснование:**
Denizz с его $1M может позволить себе зафиксировать мелкий убыток. Для нас убыток на $200 -- это 10% банкролла. Поэтому мы держим убыточные позиции дольше, если Denizz не выходит решительно (>60%).

### 3.4 Стоп-лосс (аварийный выход БЕЗ сигнала Denizz)

Даже если Denizz не продает, мы выходим, если:

```
Стоп-лосс = our_entry_price * (1 - stop_pct)
```

| Ценовой тир входа | stop_pct | Стоп-цена | Обоснование |
|-------------------|----------|-----------|-------------|
| 2-15c | 60% | Если купили по 10c, стоп на 4c | Дешевые позиции волатильны, даем больше пространства |
| 15-50c | 40% | Если купили по 40c, стоп на 24c | Основная рабочая зона, умеренный стоп |
| 50-82c | 25% | Если купили по 65c, стоп на 49c | Дорогая позиция, стоп ближе |
| 82-95c | 15% | Если купили по 90c, стоп на 77c | Мало апсайда, узкий стоп |
| 95-99c | 5% | Если купили по 97c, стоп на 92c | Минимальный апсайд, жесткий стоп |

### 3.5 Проскальзывание при выходе

При продаже мы продаем по bid, а не по ask. Нужно учитывать спред.

```
exit_slippage = denizz_sell_price - current_bid
```

Если exit_slippage > допустимого для тира (те же пороги, что при входе) -- ставим лимитный ордер вместо маркетного, или ждем улучшения bid.

### 3.6 Наша цена выхода vs цена Denizz

```
exit_advantage = our_exit_price - denizz_avg_exit
```

- Если мы продаем дороже Denizz: хорошо, выходим.
- Если мы продаем дешевле Denizz на > допустимый порог: ставим лимитный ордер ближе к цене Denizz.

## 4. Полная формула (сводка)

### ENTRY:

```
base_bet = denizz_bet_usd * 0.002

our_bet = base_bet * M_ratio * M_tier * M_slip * M_conc * M_entry * M_portsize

our_bet = max($2, min(our_bet, $200, $200 - existing_position))

Если our_bet < $2 --> НЕ ВХОДИМ
Если M_ratio = 0 --> НЕ ВХОДИМ
Если M_slip = 0 --> НЕ ВХОДИМ
Если M_conc = 0 --> НЕ ВХОДИМ
```

### EXIT:

```
sell_pct = lookup(denizz_sell_ratio)  -- из таблицы 3.2
sell_pct = adjust_for_pnl(sell_pct, our_pnl)  -- из таблицы 3.3
our_sell_amount = our_position * sell_pct

Если current_bid < stop_loss --> ПРОДАТЬ 100%
Если exit_slippage > допустимого --> ЛИМИТНЫЙ ОРДЕР
```

## 5. Десять конкретных сценариев с расчетами

### Сценарий 1: Идеальный вход -- Denizz добавляет 25% к крупной позиции

**Вводные:**
- Denizz покупает $50,000 на позицию, где у него уже $200,000
- Ratio = 50,000 / 200,000 = 25% (бакет 15-30%)
- Текущая цена: ask = 38c (тир 15-50c)
- Denizz avg entry = 36c, наш ask = 38c (slippage = 2c)
- У нас нет позиции (concentration = 0%)
- Портфель Denizz = $200,000 ($100K+ бакет)

**Расчет:**
- base_bet = $50,000 * 0.002 = $100
- M_ratio = 1.5 (бакет 15-30%, лучший)
- M_tier = 1.3 (15-50c, лучший тир)
- M_slip = max(0, 1 - 2/3) = 0.33 (2c slippage при допуске 3c)
- M_conc = 1.0 (нет существующей позиции)
- M_entry = 1.0 (мы дороже, штраф через M_slip)
- M_portsize = 1.5 ($100K+ бакет)

**our_bet = $100 * 1.5 * 1.3 * 0.33 * 1.0 * 1.0 * 1.5 = $96.53**

**Итог: ставим $96.53. Это 4.8% банкролла -- крепкий сигнал, но slippage в 2c снижает размер.**

### Сценарий 6: У нас уже большая позиция -- добавление

**Вводные:**
- Denizz покупает $40,000 на позицию, где у него $180,000

## 8. Итоговая расширенная формула

### ENTRY:

```
our_bet = base_bet * M_ratio * M_tier * M_slip * M_conc * M_entry * M_portsize * M_load

Где:
  base_bet = denizz_bet_usd * 0.002
  M_ratio = f(ratio)                     -- таблица 2.2
  M_tier = f(ask_price)                  -- таблица 2.3
  M_slip = f(slippage, tier)             -- таблица 2.4
  M_conc = f(our_position / bankroll)    -- таблица 2.5
  M_entry = f(our_price vs denizz_price) -- таблица 2.6
  M_portsize = f(denizz_portfolio)       -- таблица 2.8
  M_load = f(total_positions / bankroll) -- раздел 7

Ограничения:
  our_bet = clamp(our_bet, $2, min($200, max_position - existing, available_balance))
  Если our_bet < $2 --> ПРОПУСК
```

### EXIT:

```
1. Проверить стоп-лосс --> если сработал, продать 100%
2. Если Denizz продает:
   a. sell_pct = lookup(denizz_sell_ratio)
   b. Если our_pnl < 0 и sell_ratio < 60% --> НЕ ВЫХОДИТЬ
   c. Иначе: sell_amount = position * sell_pct
   d. Если exit_slippage > допустимого --> лимитный ордер
3. Если Denizz не продает --> держать (кроме стоп-лосса)
```

## 10. Практическая шпаргалка для принятия решений

### Быстрая проверка перед входом (5 вопросов):

1. **Ratio Denizz?** Если < 5% -- пропуск. Если 15-30% -- лучший сигнал.
2. **Ценовой тир?** 15-50c -- лучший. 95-99c -- почти никогда не входим.
3. **Slippage?** Посмотри ask, сравни с ценой Denizz. Если разница > допуска для тира -- пропуск.
4. **Наша позиция?** Если уже >8% банкролла ($160) -- минимальное добавление. Если 10% ($200) -- стоп.
5. **Загрузка портфеля?** Если >85% -- сильно режем. Если >90% -- не входим.

### Быстрая проверка при выходе (3 вопроса):

1. **Denizz продал >60%?** Выходим пропорционально.
2. **Мы в убытке?** Если да и Denizz продал <60% -- держим.
3. **Стоп-лосс сработал?** Выходим немедленно, независимо от действий Denizz.
