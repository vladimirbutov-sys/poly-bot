# Анализ: Размер докупки denizz vs движение цены

**Дата анализа**: 2026-04-13
**Период данных**: 2026-04-07 — 2026-04-13
**Всего сделок**: 3442

## Суть вопроса

Когда denizz докупает в уже существующую позицию, размер этой докупки может сигнализировать о его уверенности.
Маленькая докупка (1-3% от позиции) — возможно, просто «подбирает мелочь».
Большая докупка (30%+ от позиции) — серьёзное усиление позиции, сильный сигнал.

**Вопрос**: подтверждают ли данные, что крупные докупки дают лучший результат?

## Методология

1. Загружены все сделки denizz через Polymarket Data API (с пагинацией)
2. Для каждого токена (conditionId + asset) построена хронология покупок
3. Для каждой покупки ПОСЛЕ первой рассчитан коэффициент: `размер_покупки / сумма_предыдущих_покупок`
4. Покупки разбиты на группы по размеру коэффициента
5. Для каждой группы посчитано: максимальный рост цены за 24ч и 7 дней после покупки, винрейт

**Ограничения**: движение цены отслеживается по ценам последующих сделок denizz на том же токене.
Если denizz не торговал токеном после покупки — используется цена покупки (считаем «без изменений»).

### Важная оговорка по «пылевым» (<1%) докупкам

Группа <1% показывает WR 74.2%, но это **обманчивый результат**. Вот почему:
- Это 1482 сделки со средним размером всего $30 — denizz просто «подбирает мелочь» на уже крупных позициях
- Высокий WR отражает то, что позиция УЖЕ в плюсе и продолжает расти — мелкая докупка тут ни при чём
- Для нашего бота копировать сделку на $30 не имеет смысла (комиссии съедят прибыль)
- Последняя цена (итоговый P&L) для пыли: всего +4.0% — намного хуже, чем у крупных (+15.8%)

### Ключевые выводы

1. **Первый вход** — самый сильный сигнал: средний макс рост +40.5%, но WR(+5%) только 50.5%.
   Это значит: когда denizz входит впервые, потенциал роста огромный, но и риск высокий (каждый второй раз не срабатывает).

2. **Крупные докупки (30%+) и удвоения (>100%)** — хорошие сигналы:
   - WR 58-60%, средний макс рост +29-32%, медиана +10-11%
   - Средний размер $2966-$3106 — denizz вкладывает серьёзные деньги
   - Последняя цена показывает реальный рост: +2-16%

3. **Средние докупки (3-30%)** — умеренные сигналы:
   - WR 55-57%, макс рост +24-25%
   - Размер $1370-$1570 — нормальные покупки

4. **Микро-докупки (1-3%)** — слабый сигнал:
   - WR всего 46.4% — хуже монетки!
   - Но средний макс рост +26% — бывают удачные попадания

5. **Пылевые (<1%)** — не сигнал вообще, а шум. Пропускаем.

### Практические рекомендации для бота

| Тип покупки | Ratio | Рекомендация | Размер нашей ставки |
|-------------|-------|-------------|---------------------|
| Первый вход | — | Копируем | 100% |
| Удвоение+ | >100% | Копируем обязательно | 100% |
| Крупная докупка | 30-100% | Копируем | 100% |
| Средняя докупка | 10-30% | Копируем | 75% |
| Малая докупка | 3-10% | Копируем с осторожностью | 50% |
| Микро-докупка | 1-3% | Можно пропустить | 25% или пропуск |
| Пыль | <1% | Пропускаем | 0% |

**Порог отсечения: ratio < 3%** — такие докупки можно безопасно пропускать.
Это отсечёт ~1600 из 2000 докупок (80% шума!), но потеряем мало полезных сигналов.

**Масштабирование**: для докупок выше порога — размер нашей ставки пропорционален ratio:
- `наша_ставка = base_bet * min(1.0, ratio / 0.30)`
- Это значит: при ratio = 30%+ ставим полную сумму, при ratio = 15% — половину, при ratio = 5% — шестую часть.
