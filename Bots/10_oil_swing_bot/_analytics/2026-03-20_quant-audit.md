## ЧАСТЬ 5: МАТЕМАТИЧЕСКАЯ ОЦЕНКА СТРАТЕГИИ

### EV NO-стратегии

По историческим данным (исключая ликвидации старых позиций):

```
Автоматических NO-сделок: 6
Побед: 5 (win rate = 83%)
Средний gain при победе: +59% (взвешенный по размеру: +47%)
Средний loss при поражении: ~15% (оценка по NO→$91 stop)

Базовый EV = 0.83 × 47% - 0.17 × 15% = 36.5% за сделку
```

**С учётом теты (×0.48):**
```
EV_theta = 36.5% × 0.48 = 17.5%
```

**С учётом декорреляции (×0.40):**
```
EV_adjusted = 17.5% × 0.40 = 7.0%
```

### Максимальный риск NO-позиции

Если WTI пробьёт $100 и рынок закроется YES — все NO = $0.

```
P(WTI >= $100) = 66% (Polymarket)
P(NO total loss | открыта) = 66% × P(позиция открыта при пробое)
```

Среднее время в позиции = 8 часов. За 8 часов вероятность пробоя $100 от текущих $94.5:
```
Движение +$5.5 за 8ч ≈ $5.5 / ($4.17 × √(8/24)) ≈ 2.28σ → P ≈ 1.1%
```

Но бот входит в NO при WTI $97-99, когда до $100 всего $1-3:
```
При WTI $98: движение +$2 за 8ч ≈ $2 / ($4.17 × 0.577) ≈ 0.83σ → P ≈ 20%
```

**Это главный риск:** при входе на step 1 ($98) вероятность того что WTI пробьёт $100 за время удержания = ~20%. При этом потеря = 100% от ставки ($10).

### Kelly criterion

```
EV = 7%  (после теты и декорреляции)
Max loss = 100% (WTI >= $100)
P(loss) ≈ 20% (при входе у $98)

Kelly fraction = EV / max_loss = 7% / 100% = 7% от банкролла
Kelly bet = $340 × 7% = $24
```

Текущие ставки: step 0 = $10, step 1 = $10, step 2 = $15. Сумма = $35 > Kelly $24.

**Вывод:** совокупная ставка ($35) **превышает Kelly** на 46%. При декорреляции нужно снижать.

### Ожидаемая прибыль до дедлайна

```
Оставшиеся циклы WTI: ~3-4 (по 2 дня на цикл)
EV за цикл: 7% × $10-15 = $0.70 - $1.05
Ожидаемая доп. прибыль: $3 - $5
```

Но если повезёт (WTI осцилляция продолжится, декорреляция исправится):
```
Оптимистичный сценарий: 3 × 47% × $12 = $17
Пессимистичный: 1 потеря $10-15 = -$10-15
```

**Диапазон:** от -$15 до +$20. Текущий P&L +$41 — уже хороший результат.
