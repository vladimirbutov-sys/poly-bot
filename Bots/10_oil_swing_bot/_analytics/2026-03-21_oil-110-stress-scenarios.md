## Вопрос

При каких стресс-сценариях WTI может подняться до $110 по CME settlement price до 31 марта 2026?

## Условия резолюции

- Рынок = **YES**, если на **любой торговый день** официальная CME settlement price для Active Month (фронтальный месяц) CL >= $110
- Только settlement price (не intraday, не bid/ask, не last trade)
- Активный месяц становится неактивным за 2 рабочих дня до экспирации спот-месяца
- **Фронт-месяц на конец марта: май 2026 (CLK26)**
- Дедлайн: последний торговый день марта = **31 марта 2026 (вторник)**

### Gap-анализ

```
Текущий settlement: $98.32
Цель: $110.00
Gap: $11.68 (11.9%)

При vol 70% (годовой):
  σ_daily = $98.32 × 0.70 / √252 = $4.33
  Gap в сигмах: $11.68 / $4.33 = 2.70σ (за 1 день)

  За 8 дней (random walk):
  σ_8d = $4.33 × √8 = $12.25
  z-score = $11.68 / $12.25 = 0.95
  P(WTI >= $110 хотя бы раз за 8 дней) ≈ 17-25%

При vol 135% (измеренная из данных):
  σ_daily = $98.32 × 1.35 / √252 = $8.36
  Gap в сигмах: $11.68 / $8.36 = 1.40σ (за 1 день)

  За 8 дней:
  σ_8d = $8.36 × √8 = $23.64
  z-score = $11.68 / $23.64 = 0.49
  P(WTI >= $110 хотя бы раз за 8 дней) ≈ 31-40%
```

**Вывод:** Математическая вероятность пробоя $110 за 8 дней = **17-40%** в зависимости от волатильности. Polymarket даёт 26.5% — ровно посередине, рынок корректно оценивает.

- Паника на рынках → WTI +$10-15 за 1-2 дня

**Индикаторы для мониторинга:**

- Общий дефицит достигает 25% мирового потребления
- Рынок уходит в полную панику → WTI $110-130+
**Скорость:** Мгновенная (часы). Settlement в тот же день или на следующий

**Индикаторы:**

**Скорость:** 1-2 дня
**Индикаторы:** Непредсказуемо по определению

## ЧАСТЬ 4: МАТЕМАТИЧЕСКАЯ МОДЕЛЬ

### Random Walk с дрейфом

```
Параметры:
  S0 = $98.32 (текущий settlement)
  Target = $110.00
  T = 8 торговых дней
  σ_daily = $4.33 (vol 70%) или $8.36 (vol 135%)

Модель 1: vol 70%, без дрейфа
  P(max(S_1..S_8) >= $110) ≈ 17%

Модель 2: vol 135%, без дрейфа
  P(max(S_1..S_8) >= $110) ≈ 38%

Модель 3: vol 70%, дрейф +$0.5/день (геополитическая премия)
  P(max(S_1..S_8) >= $110) ≈ 22%

Модель 4: vol 70%, дрейф -$0.5/день (IEA резервы давят)
  P(max(S_1..S_8) >= $110) ≈ 13%
```

### Jump-diffusion модель (более реалистичная)

Нефть в кризис НЕ ходит random walk — она прыгает на новостях. Добавляем "прыжки":

```
Параметры:
  λ = 0.15 (15% шанс прыжка в любой день)
  Jump size: N(+$8, $4) — при прыжке WTI скачет на $4-12

P(WTI >= $110 хотя бы раз за 8 дней) ≈ 25-30%
```

Это ближе к оценке Polymarket (26.5%).

### Что нужно для settlement $110

**Важно: settlement ≠ intraday high.** Settlement — это расчётная цена CME в 14:28-14:30 ET. Это средневзвешенная цена за 2-минутное окно.

```
WTI уже был на $115.88 INTRADAY, но settlement мог быть ниже.
Для settlement $110 нужно:
  1. WTI торгуется ВЫШЕ $110 к 14:30 ET
  2. Цена устойчива (не spike/flash)
  3. Достаточный объём торгов в окне settlement
```

Это значит: однократный spike до $110 в 3 утра НЕ считается. Нужно, чтобы рынок был ВЫШЕ $110 во время settlement window (14:28-14:30 ET).

## ЧАСТЬ 6: АНАЛИЗ РЫНКА POLYMARKET $110

### Текущее состояние

| Параметр | Значение |
|----------|----------|
| YES $110 | 26.5¢ |
| NO $110 | 73.5¢ |
| Объём | $4.54M |
| Дедлайн | 31 марта 2026 |

### Справедливая цена (по моим моделям)

| Модель | Fair YES $110 | Edge vs рынок |
|--------|---------------|---------------|
| Random walk (vol 70%) | 17% | Рынок переоценивает YES |
| Random walk (vol 135%) | 38% | Рынок недооценивает YES |
| Jump-diffusion | 25-30% | Рынок в цене |
| Среднее | **27%** | **Рынок оценивает корректно** |

### EV покупки YES $110

```
Покупка YES по 26.5¢:
  Если YES: получаю $1.00 → прибыль 73.5¢ (+277%)
  Если NO: теряю 26.5¢ (-100%)

  EV при P=27%: 0.27 × 0.735 - 0.73 × 0.265 = 0.198 - 0.193 = +0.005
  EV = +$0.005 на каждый $1 ставки = +0.5%
```

**EV практически нулевой.** Рынок эффективно оценивает вероятность. Нет явного edge.

### EV покупки NO $110

```
Покупка NO по 73.5¢:
  Если NO: получаю $1.00 → прибыль 26.5¢ (+36%)
  Если YES: теряю 73.5¢ (-100%)

  EV при P(NO)=73%: 0.73 × 0.265 - 0.27 × 0.735 = 0.193 - 0.198 = -0.005
  EV = -$0.005 = -0.5%
```

**Тоже нулевой.** Не стоит ставить на NO $110 "в лоб".

## ЧАСТЬ 7: ВЛИЯНИЕ НА ТЕКУЩИЙ БОТ (10_oil_swing_bot)

### Бот торгует рынок $100, не $110

Бот работает с токенами YES/NO на рынке "WTI >= $100 к концу марта". Но параметр `STOP_NO_WTI = $110` напрямую связан с рынком $110.

### Риск для NO-позиций бота

```
Если WTI settlement >= $110:
  1. Рынок $100 резольвится YES → все NO $100 = $0 (полная потеря)
  2. STOP_NO_WTI = $110 сработает, но ПОЗДНО — при $110 NO $100 уже стоит ~1-3¢

Если WTI settlement >= $100 (но < $110):
  1. Рынок $100 резольвится YES → все NO $100 = $0
  2. STOP_NO_WTI НЕ сработает (только при $110)
```

**Проблема:** Стоп на $110 бесполезен для защиты NO $100. К моменту, когда WTI дойдёт до $110, позиция уже потеряна. Реальный стоп для NO $100 — это graduated stop (в strategy.py), который срабатывает при $101-108 в зависимости от времени до settlement.

### Рекомендации для бота

1. **STOP_NO_WTI = $110 → снизить до $105-107.** При $110 уже поздно. Graduated stop в strategy.py помогает, но STOP_NO_WTI — это паническая кнопка, она должна срабатывать раньше.

2. **Учитывать settlement цену, а не intraday.** Бот мониторит WTI через Yahoo Finance (intraday), но резолюция по settlement. WTI может быть $109 intraday, но settlement $106 — рынок не резольвится.

3. **Последние 7-8 дней — максимальная осторожность.** Оставшееся время совпадает с зоной, где тета ускоряется (profit_mult = 0.09). Новые NO-позиции имеют EV ~0.

## ЧАСТЬ 8: ИТОГОВАЯ ОЦЕНКА

### Вероятность WTI settlement >= $110 до 31 марта

| Оценка | Значение |
|--------|----------|
| Polymarket | **26.5%** |
| Random walk (vol 70%) | 17% |
| Random walk (vol 135%) | 38% |
| Jump-diffusion | 25-30% |
| Экспертная (с учётом геополитики) | **25-30%** |

### Что должно произойти для $110

**Минимально необходимое:**
1. WTI должен вырасти на $12 (+12%) от текущего settlement
2. Рост должен произойти ДО settlement window (14:28-14:30 ET)
3. Цена должна быть УСТОЙЧИВОЙ в момент settlement (не spike)

**Наиболее вероятный путь:**
- Новая эскалация (удар по инфраструктуре или вторая волна операции) → WTI gap up $8-15 за 1-2 дня → settlement проходит $110

**Наименее вероятный путь:**
- Постепенный рост на $1.5/день × 8 дней = $12 → возможен, но обычно рынок так не ходит в кризис, он прыгает

### Матрица решений для трейдера

| Действие | Когда | EV |
|----------|-------|-----|
| Покупить YES $110 по 26.5¢ | Есть собственный анализ что эскалация вероятна | ~0% (рынок в цене) |
| Покупить NO $110 по 73.5¢ | Консервативная ставка "время кончается" | ~0% (рынок в цене) |
| НЕ торговать $110 | По умолчанию | Лучший вариант |
| Хеджировать NO $100 через YES $110 | Если есть крупная NO $100 позиция | Страховка от хвостового риска |

### Финальный вердикт

**$110 settlement — это tail risk event.** Он уже произошёл один раз в этом месяце (WTI $115.88) и может повториться. Но Polymarket корректно оценивает вероятность в ~26%. Edge для трейдера нет.

Для бота 10_oil_swing_bot главный вывод: **стоп STOP_NO_WTI на $110 слишком далеко.** Нужно опустить до $105-107, потому что при $110 NO $100 уже стоит 0-3 центов — спасать нечего.
