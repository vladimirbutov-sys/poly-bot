# Структура комиссий Polymarket (апрель 2026)

## Общая модель

Polymarket использует модель **maker/taker**:
- **Maker (лимитные ордера)** — бесплатно на глобальной платформе
- **Taker (маркет-ордера)** — платные, ставка зависит от категории рынка

Комиссии были введены постепенно начиная с января 2026 (до этого торговля была бесплатной).

| Категория | Taker Fee |

| Crypto | 1.80% |

| Culture / Weather | 1.25% |
| Finance / Politics / Tech | 1.00% |
| Sports | 0.75% |
| Geopolitics | 0% (бесплатно) |

## US-биржа (polymarketexchange.com)

На регулируемой US-бирже другая модель:
- Taker fee: **0.30%** (единый для всех категорий)
- Maker rebate: **0.20%** (мейкеры получают вознаграждение)

## Формула расчёта комиссии

```
fee = shares × feeRate × p × (1 − p)
```

Где **p** — вероятность (цена акции от 0 до 1).

Это создаёт колоколообразную кривую:
- При p = 0.50 (50¢) — комиссия максимальная
- При p близкой к 0 или 1 — комиссия стремится к нулю

### Примеры (для категории Sports, 0.75%):
- 100 акций по 50¢: fee = 100 × 0.0075 × 0.5 × 0.5 = **0.1875 USDC**
- 100 акций по 90¢: fee = 100 × 0.0075 × 0.9 × 0.1 = **0.0675 USDC**
- 100 акций по 95¢: fee = 100 × 0.0075 × 0.95 × 0.05 = **0.0356 USDC**

## Покупка vs Продажа

Правила одинаковые:
- Покупка через маркет-ордер = taker fee
- Продажа через маркет-ордер = taker fee
- Покупка через лимитный ордер = бесплатно
- Продажа через лимитный ордер = бесплатно

## Выплата выигрыша

Когда рынок резолвится в пользу держателя — **комиссий нет**. Полная выплата $1 за акцию.

## Другие комиссии

- **Депозиты:** бесплатно со стороны Polymarket (сторонние сервисы вроде MoonPay могут брать свои комиссии)
- **Вывод:** бесплатно со стороны Polymarket (минимальная gas-комиссия Polygon, обычно несколько центов)

## Практические выводы для бота

1. **Лимитные ордера = нулевые комиссии** — если бот работает через limit orders, комиссий нет
2. **Высокие вероятности (95¢+) = минимальные комиссии** даже для taker — формула p×(1-p) делает их почти нулевыми
3. **Категория имеет значение** — крипто-рынки в 2.4 раза дороже спортивных
4. **Геополитика полностью бесплатна** — если бот находит подходящие рынки в этой категории, это чистая экономия
