# Влияние комиссий Polymarket на 98_sure_bot

**Дата анализа:** 2026-03-25
**Комиссии вступают в силу:** 30 марта 2026

---

## Вывод: комиссии ПОЧТИ НЕ ВЛИЯЮТ на бота

Формула комиссии `fee = C × p × feeRate × (p × (1-p))^exponent` работает **в пользу** нашего бота.

Ключевой множитель `p × (1-p)` при наших ценах:
- p = 0.99 → p×(1-p) = **0.0099** (почти ноль!)
- p = 0.985 → p×(1-p) = **0.0148**
- p = 0.50 → p×(1-p) = **0.25** (максимум — в 17-25 раз больше)

Мы покупаем на краю (96-99.5%), где комиссия минимальна по дизайну.

## Почему бот почти не затронут

1. **Формула на нашей стороне.** Множитель p×(1-p) при p=0.99 равен 0.01 — в 25 раз меньше, чем при p=0.50. Polymarket сделал комиссию минимальной для экстремальных цен.

2. **Geopolitics бесплатна.** 23 ставки (8% объёма) — без комиссий вообще.

3. **Категория "Other" — почти бесплатна.** При exponent=2 множитель (p×(1-p))² при p=0.99 = 0.0001. Комиссия $0.04 на $972 объёма.

4. **Мы ставим лимитные ордера → получаем maker rebate.** Это снижает комиссию ещё на 25-50%.

---

## Рекомендации

1. **Ничего менять не нужно.** Комиссии не угрожают стратегии.
2. **MAX_PRICE = 0.995 можно оставить.** Даже при 0.995 комиссия (0.02%) не существенна по сравнению с ROI (0.50%).
3. **Политика (0.96+) остаётся выгодной.** Комиссия 0.05% при ROI 3.4% — несущественно.
4. **Единственный риск — категория Crypto (feeRate=0.072).** Но у бота всего 6 крипто-ставок, и даже там комиссия 0.075% при ROI ~1%.

## Прогноз при масштабировании

При увеличении банкрола до $1,000 и объёме $10,000/месяц:

| Сценарий | Комиссия/месяц | Как % от прибыли |
|----------|---------------|-----------------|
| Текущий микс категорий | ~$2.60 | ~5% |
| Только спорт | ~$3.90 | ~7% |
| Только политика 96%+ | ~$5.20 | ~4% (выше ROI компенсирует) |

Комиссии остаются пренебрежимо малыми при любом реалистичном масштабе.
