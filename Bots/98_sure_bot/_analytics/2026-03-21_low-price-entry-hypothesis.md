## 6. КРИТИЧЕСКИЙ АНАЛИЗ: ЗА И ПРОТИВ

### АРГУМЕНТЫ ЗА снижение порога

1. **Больший ROI на позицию.** При входе по 90с и победе прибыль = 10с/шару (11.1% ROI), против 1-3с/шару при 97-99с (1-3% ROI). В 5-10 раз больше прибыли на ставку.

2. **Политика — предсказуемая категория.** Win rate 73% при >= 97с — лучший среди не-спортивных. Рынки типа "Will X be president?" или "Will sanctions be lifted?" часто имеют очевидные исходы задолго до закрытия.

3. **Медленная динамика цен.** Политические/геополитические события разворачиваются неделями/месяцами, в отличие от спорта (часы). Меньше "внезапных" переворотов.

4. **Диверсификация.** Сейчас бот привязан к узкому окну 96-99.5с. Расширение позволит ловить возможности, которые сейчас пропускаются.

### АРГУМЕНТЫ ПРОТИВ снижения порога

1. **НЕТ ДАННЫХ для бэктеста.** Самый важный аргумент. Мы не можем проверить гипотезу — 97_scanner не собирает данные < 96с, 21_car_copybot никогда не работал. Решение будет слепым.

2. **API показывает 0% win rate при < 85с.** В 45 из 45 известных случаев рынок оказался прав — исход с ценой < 85с не наступил. Рынок эффективен в предсказании маловероятных событий.

3. **Рост риска в 5-10 раз.** При цене 90с потеря = $9 на $10 ставку (90%). При цене 98с потеря = $9.80 (98%), но вероятность потери гораздо ниже. Одно поражение при 90с стирает прибыль от ~90 побед при 99с.

4. **Tech — опасная категория (25.4% WR).** Даже при текущем пороге 97с+ tech показывает худший win rate. Снижение порога для tech — это увеличение убытков.

5. **Ложное чувство безопасности.** "Медленные категории" — не значит "безопасные". Геополитика (53% WR) теряет деньги даже при 97с+ без фильтров. Украина-Россия, Иран, Тайвань — рынки могут перевернуться за день.

6. **Ликвидность падает с ценой.** Рынки с ценой 90с имеют меньшую ликвидность — сложнее войти/выйти, больше проскальзывание.

## 7. МАТЕМАТИЧЕСКАЯ МОДЕЛЬ

### Текущая стратегия (98-99с):
- Средний вход: 98.5с
- Win rate (реальный): ~98%
- Прибыль на победу: ~$0.075 (при $5 ставке)
- Потеря на поражение: ~$4.93
- EV на ставку: 0.98 × $0.075 - 0.02 × $4.93 = **+$0.075 - $0.099 = -$0.024**

Негативный EV? Нет — реальный win rate > 99%, бот за 201 ставку имеет 1 поражение (и то из-за бага redeemer). Истинный EV положительный.

### Гипотетическая стратегия (90с, политика):
- Средний вход: 90с
- Win rate (неизвестен, оценка): 80-90%?
- Прибыль на победу: ~$0.50 (при $5 ставке)
- Потеря на поражение: ~$4.50
- EV при 85% WR: 0.85 × $0.50 - 0.15 × $4.50 = **+$0.425 - $0.675 = -$0.25**
- EV при 90% WR: 0.90 × $0.50 - 0.10 × $4.50 = **+$0.45 - $0.45 = $0.00**
- **Нужен WR > 90% чтобы стратегия была прибыльной при 90с!**

### Зона безубыточности по цене:

| Цена входа | Нужный Win Rate для EV > 0 |
|---|---|
| 99с | > 99.0% |
| 98с | > 98.0% |
| 96с | > 96.0% |
| 94с | > 94.0% |
| 90с | > 90.0% |
| 85с | > 85.0% |

Правило простое: при цене Xс нужен win rate > X%. Данные 97_scanner показывают что для политики при >= 97с WR = 73% — это **НИЖЕ** нужного порога 97%. Бот добивается 98%+ только благодаря жёстким фильтрам.

## Методология

- **97_scanner:** 26,193 записей из scanner_data.json. Все рынки first_price >= 97%. Разбивка по категориям и ценовым бакетам
- **98_sure_bot:** 201 позиция из positions.json. Анализ win rate по категориям

- **Polymarket API:** Прямой запрос закрытых рынков politics/geopolitics по ценовым бакетам (выборка ~100)
- **Математическая модель:** EV = WR × profit - (1-WR) × loss. Расчёт безубыточного WR для каждого ценового уровня
- **Бэктест невозможен** для цен < 96с — данные не собирались. Рекомендации основаны на теоретическом анализе + выборка API
