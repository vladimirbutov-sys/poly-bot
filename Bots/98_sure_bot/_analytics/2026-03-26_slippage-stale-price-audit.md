## ИССЛЕДОВАНИЕ 2: STALE PRICE DIVERGENCE

### Все stale price skip события (7 уникальных рынков)

| Рынок | Gamma | CLOB | Divergence |
|---|---|---|---|
| CS: CSDIILIT vs MANA - Map 1 Winner | 0.981 | 0.840 | **14.1c** |
| CS: Rebels Gaming vs Ursa (BO3) | 0.975 | 0.863 | **11.2c** |
| Dota 2: Team Falcons vs Virtus.pro | 0.979 | 0.885 | **9.4c** |
| LoL: French Flair vs Galions - Game 2 | 0.978 | 0.914 | **6.4c** |
| Trump says "Biden/Obama" 7+ times | 0.980 | 0.925 | **5.5c** |
| CS: Lavked vs Hashiras - Map 1 | 0.979 | 0.920 | **5.9c** |
| CS: BIG vs MOUZ NXT (BO3) | 0.989 | 0.948 | **4.1c** |

**Статистика:**
- Всего: 7 уникальных рынков (14 строк в логе — каждый дублируется)
- Средняя divergence: **8.1c** (range: 4.1c — 14.1c)
- Все 7 — **спорт/киберспорт или live events**

### Анализ: были ли это безопасные покупки?

**НЕТ.** Все 7 рынков — это ситуации где:
1. Gamma API показывал стартовую цену (97-98c) — **кэшированную до начала матча**
2. CLOB показывал РЕАЛЬНУЮ цену (84-95c) — **после того как ситуация в матче изменилась**
3. Цена CLOB ниже 96c для 5 из 7 рынков — **ниже нашего порога входа**
4. Единственные два с CLOB > 94c (Trump 7+ times: 0.925, BIG vs MOUZ: 0.948) — всё равно ниже 96c

**Вывод:** Текущий MAX_PRICE_DIVERGENCE = 0.03 (3c) **работает правильно**. Все 7 skip были обоснованы — рынок действительно сдвинулся.

### Стоит ли поднимать MAX_PRICE_DIVERGENCE до 0.05?

**НЕТ.** Анализ показывает:

| Если бы порог был | Пропустило бы | Риск |
|---|---|---|
| 0.03 (текущий) | 0 из 7 | Все заблокированы |
| 0.05 | 2 из 7 (BIG vs MOUZ 4.1c, Trump 5.5c) | CLOB цены 0.925 и 0.948 — обе ниже нашего MIN_PRICE 0.96 |
| 0.10 | 5 из 7 | CLOB цены 0.84-0.92 — очень высокий риск |

Даже при пороге 0.05 мы бы попали в рынки с CLOB ценой 0.925 и 0.948 — оба ниже нашего порога 0.96. Бот бы поставил по 97-98c (Gamma цена + slippage) на рынок, где реальная цена 92-95c. **Это переплата в 3-5c и повышенный риск.**

### Техническое решение: двухфазная проверка цены

Вместо увеличения порога, предлагаю улучшить точность:

**Текущая логика:**
```
1. Gamma API → цена 0.98
2. CLOB midpoint → цена 0.88
3. Diff = 0.10 > 0.03 → SKIP
```

**Предлагаемая логика (адаптивная):**
```
1. Gamma API → цена 0.98
2. CLOB midpoint → цена 0.88
3. Diff = 0.10 > 0.03 → STALE DETECTED
4. Проверяем: CLOB цена 0.88 >= MIN_PRICE (0.96)?
   - НЕТ (0.88 < 0.96) → SKIP (рынок действительно ушёл)
   - ДА → Пересчитать ставку по CLOB цене, поставить
```

**Когда это поможет:**
- Gamma показывает 0.98, CLOB показывает 0.97 (diff = 1c < 3c) — текущая логика и так пропускает
- Gamma показывает 0.98, CLOB показывает 0.965 (diff = 1.5c < 3c) — текущая логика и так пропускает
- Gamma показывает 0.98, CLOB показывает 0.961 (diff = 1.9c < 3c) — текущая логика и так пропускает

**Вывод:** При текущем пороге 3c практически ВСЕ случаи где CLOB >= 0.96 уже проходят проверку. Двухфазная логика не даст заметного улучшения.

**ИТОГ по stale price: текущая настройка MAX_PRICE_DIVERGENCE = 0.03 ОПТИМАЛЬНА. Менять не нужно.**

### План тестирования (если всё же внедрять адаптивную проверку):

1. **Добавить детальное логирование:** при каждом stale skip логировать CLOB цену, проверку vs MIN_PRICE
2. **Shadow mode (2 недели):** при stale skip проверять, прошёл бы рынок по CLOB цене — логировать "WOULD HAVE BOUGHT" vs "CORRECTLY SKIPPED"
3. **Метрика успеха:** если >20% stale skip рынков имели бы CLOB >= 0.96 И потом resolved в нашу пользу
4. **Метрика провала:** если хоть один из "WOULD HAVE BOUGHT" рынков потом resolved ПРОТИВ нас — стратегия опасна

**Главный вывод:** Проблема fill rate (79% ставок не исполнено) **НЕ решается только slippage**. Основные причины:
1. CLOB ликвидность — на многих рынках 99c+ нет встречных ордеров
2. Конкуренция — другие боты ставят раньше
3. Слишком частые попытки — бот пытается купить один и тот же рынок повторно после timeout

**Рекомендация по архитектуре:** Добавить cooldown 30 мин на рынок после timeout, чтобы не тратить ордера на неликвидные рынки.
