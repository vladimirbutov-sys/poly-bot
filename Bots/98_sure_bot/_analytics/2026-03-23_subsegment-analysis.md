## 6. Ответ на вопрос: стоит ли ставить только на исход матча?

**НЕТ.** Причины:

1. **Потеря 82% объёма**: с 7,331 до 1,309 рынков. При банкролле $800 бот будет простаивать большую часть времени
2. **Очень медленный resolve**: match_outcome — 164h медиана. Деньги замороженны ~7 дней
3. **Маленький выигрыш в безопасности**: loss rate падает с 0.49% до 0.15%, но при текущем объёме бота (180 сделок) это разница в 0-1 потерю
4. **Лучше убрать конкретные токсичные сегменты**: weather + props дают 23 из 36 потерь (64%), а занимают всего 1,957 из 7,331 рынков (27%)

### ОПЦИОНАЛЬНО:

#### 4. Рассмотреть удаление всех threshold рынков

#### 5. НЕ трогать sub_match рынки
- **0 потерь** на 82 рынках, +0.84% ROI, быстрый resolve (4h)
